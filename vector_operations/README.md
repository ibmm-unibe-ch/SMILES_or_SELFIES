# Vector operations on embeddings
There are two main files in this folder:
- `moleculespacecreation.ipynb`: where one can have a look at the molecules chosen for our analyses
- `latent_geometry_hydrocarbon.ipynb`: 
    - you can create a heatmap comparing the embeddings of the chosen molecules with cosine similarity within each model
    - explore vector operations in the style of `Embedding_A - Embedding_B + Embedding_C` and compare outcomes of the different models
    - explore linear decomposition and the main components returned by each model as found using LASSO regression
